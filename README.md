# PHIORA — Multipage Website

Static website, ready for GitHub Pages.

## Pages
- `index.html` — Home
- `about.html` — About
- `intelligence.html` — Explore / Reason / Insight
- `technology.html` — Technology direction
- `roadmap.html` — Development phases
- `faq.html` — FAQ

## Deploy to GitHub Pages
1. Extract ZIP. Upload the six HTML files, README, and entire `assets` folder to the **repository root**.
2. In GitHub Settings → Pages, choose **Deploy from a branch**, `main`, `/(root)`, Save.
3. Visit the GitHub Pages URL after deployment.

## Contract address
No CA has been supplied. The bottom field displays **Not announced yet**; the Copy button will not copy a fake CA.
To publish the actual address later, edit the `value` of `<input id="contract-address">` in each HTML file, or implement a shared config. Do not enter an unverified CA.
